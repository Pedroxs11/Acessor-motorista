# Acessor Motorista

Aplicativo multiplataforma para analisar ofertas de Uber, 99 e iFood conforme os criterios definidos pelo motorista.

## MVP
- Valor, distancia e tempo
- Origem e destino
- Categoria da oferta
- R$/km e R$/hora
- Resultado: BOA ou RUIM
- Historico das ofertas
- Arquitetura Android e iOS

O MVP nao realiza o clique automatico no botao de aceitar da plataforma.
